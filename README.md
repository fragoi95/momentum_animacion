# Momentum y energía cinética — simulador interactivo

**Francisco Goitia** · francisco.goitia@upc.edu

Dos esferas se mueven horizontalmente entre paredes fijas e idealmente elásticas, chocando entre ellas. Se pueden modificar las masas, las velocidades iniciales y la velocidad de reproducción.

En la zona superior de la simulación se muestran, en tiempo real, la velocidad, el momento lineal y la energía cinética de cada esfera. Debajo se comparan la energía total inicial y la actual, y su diferencia.

El momento lineal de las dos esferas se conserva cuando chocan entre ellas; no se conserva necesariamente durante los rebotes en paredes porque reciben un impulso externo. La energía cinética total se conserva en ambos tipos de choque ideales.

## Uso
